# HR Analytics Portfolio

SQL | PostgreSQL | Power BI | HR Analytics

I'm building my skills in data analytics through hands-on projects focused on workforce reporting, HR data quality, and compliance analytics.

This portfolio includes projects where I worked with synthetic datasets, designed relational databases, wrote SQL queries, and built Power BI dashboards to explore and present data.

## Projects

### 01. HR Workforce Analytics

**Tools:** PostgreSQL | SQL | Power BI

An end-to-end analytics project focused on cleaning employee data and analyzing workforce trends.

**What I worked on:**
- Cleaned and standardized employee records using SQL.
- Identified duplicate records and data quality issues.
- Analyzed employee headcount by department and location.
- Examined average salary and monthly hiring patterns.
- Built an interactive Power BI dashboard.

[View Project Repository](https://github.com/jamiemariedizon/HR-Workforce-Analytics)
